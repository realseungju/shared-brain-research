# 선택형 개인 관리 기능 추가

## 목적

사용자가 실제로 요청할 때만 개인 일정·아이디어 관리 기능을 설계한다.
현재 `personal/`은 확장 지점만 제공하며 관리 기능은 구현하지 않는다 (ADR-002).

연구 문서 관리는 이 task에서 분리됐다 — `research/`는 관례·템플릿까지 도입 완료(ADR-001).
그때 닫힌 task는 `examples/tasks/T2026-07-28-research-conventions.md`에 예시로 남아 있다.

## 착수 조건

- [ ] 사용자가 실제 사용 사례를 요청했다.
- [ ] 저장할 데이터의 공개·비공개 경계를 정했다.
- [ ] 구현 전 별도 Spec을 승인했다.

## 할 일

- [ ] 일정·할 일 입력 포맷 결정
- [ ] 아이디어 저장·검색 방식 결정
- [ ] 개인정보의 Git 추적 여부 결정 (공개 저장소면 기본 비추적)
- [ ] 생성기·lint 추가 여부 결정

## 비범위

- 외부 캘린더 동기화
- 실제 개인 일정·아이디어 예제
- 사용자 요청 없는 선제 구현

## 완료 조건

- [ ] 실제 사용자 요구가 문서화됐다.
- [ ] 요청된 범위만 구현됐다.
- [ ] 샘플 데이터는 전부 가상 데이터다.
- [ ] 기본 Tier 0 읽기 비용이 증가하지 않았다.
